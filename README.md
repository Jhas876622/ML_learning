# ML_learning

A collection of machine learning topic notebooks exploring a variety of algorithms, techniques, and workflows. This repository grows continuously as new notebooks and datasets are added.

## 📁 Repository Structure

```
ML_learning/
├── Decision Tree Regression.ipynb
├── Feature Selection.ipynb
├── K-Fold Cross Validation.ipynb
├── Multiple Linear Regression.ipynb
├── Polynomial Linear Regression.ipynb
├── Support Vector Regression on Insurance Cost.ipynb
├── TSNE.ipynb
├── bank_note_data.csv
├── data_for_lr.csv
├── test.csv
├── datasets.zip
└── README.md
```

## 📘 Overview

This repository documents a hands-on machine learning learning journey using Jupyter Notebooks. Each notebook explains an ML concept through step-by-step code, mathematical understanding, visualization, and evaluation.

## 🧠 Included Notebooks

* **Decision Tree Regression** – Implementing decision tree-based regression.
* **Feature Selection** – Methods to identify the most important predictors.
* **K-Fold Cross Validation** – Model validation method to test model generalization.
* **Multiple Linear Regression** – Regression using multiple independent variables.
* **Polynomial Linear Regression** – Extending linear regression to non-linear relationships.
* **Support Vector Regression on Insurance Cost** – Applying SVR to a real-world dataset.
* **TSNE** – Dimensionality reduction for visualization.

## 📊 Datasets

* **bank_note_data.csv** – Classification dataset.
* **data_for_lr.csv** – Regression dataset.
* **test.csv** – General-purpose dataset.
* **datasets.zip** – Additional ML datasets.

## 🚀 Getting Started

### Clone the repository

```bash
git clone https://github.com/your-username/ML_learning.git
cd ML_learning
```

### Install dependencies

```bash
pip install numpy pandas scikit-learn matplotlib seaborn
```

### Run Jupyter Notebook

```bash
jupyter notebook
```

Open any `.ipynb` file to begin exploring.
